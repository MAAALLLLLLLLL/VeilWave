# Contributing

Thank you for considering a contribution.

- Keep research features, proposed features, and experimentally validated results clearly separated.
- Do not add claims about speech-quality improvement, detector accuracy, clinical use, Raspberry Pi performance, or hardware validation without documented evidence.
- Include or update automated tests for code changes.
- Do not commit audio datasets, trained weights, private recordings, personal information, or credentials.
- Explain the Python version, operating system, dependencies, and exact command used when reporting a bug.
- Changes to the manuscript-facing algorithm should also update `PAPER_COMPATIBILITY.md`.
